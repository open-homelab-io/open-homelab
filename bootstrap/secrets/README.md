# Secret Bootstrap

This directory should document secret dependencies, not store live secret values.

Recommended model:

1. Store operational secrets in OpenBao or another external backend.
2. Use External Secrets Operator to project those values into Kubernetes.
3. Use SOPS with age for any secret that must be committed.
4. Keep Proxmox API tokens, OpenBao root/unseal material, Route53 credentials, and Talos secrets outside plaintext Git.

Minimum bootstrap inputs:

- Proxmox API token for CDKTN/Terraform.
- Talos cluster secrets generated by `talosctl gen secrets`.
- Secret backend recovery material.
- IAM Roles Anywhere certificate/key material for cert-manager and ExternalDNS Route53 automation.

The old static Route53 access-key secret path has been removed. DNS automation is bootstrapped with:

```bash
scripts/bootstrap-rolesanywhere-ca.sh
cd infra/aws && AWS_DNS_AUTOMATION_ENABLED=1 bun run deploy open-homelab-dns-automation && cd ../..
scripts/bootstrap-rolesanywhere-dns.sh
```
